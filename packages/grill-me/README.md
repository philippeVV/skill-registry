# grill-me

Interview the user relentlessly about a plan or design until reaching shared
understanding, resolving each branch of the decision tree.

## Usage

Trigger by asking Claude to "grill me" on a plan, or by invoking the skill
directly. Claude will walk through each design decision one-by-one, offering
a recommended answer for each question.
