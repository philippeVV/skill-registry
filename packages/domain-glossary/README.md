# domain-glossary

An example knowledge package demonstrating the knowledge type. Contains
a glossary of skill registry terminology.

## Purpose

This package serves as a reference implementation for the `knowledge` type.
It demonstrates:
- The KNOWLEDGE.md artifact format
- How knowledge packages are indexed and retrieved on demand
- How the knowledge-retriever skill loads relevant content

## Install

```bash
skr install domain-glossary
```

Installs to `~/.claude/knowledge/domain-glossary/KNOWLEDGE.md` and adds
an entry to `~/.claude/knowledge/index.json`.
