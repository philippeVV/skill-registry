# Architecture Decision Records

This directory contains ADRs for the skill registry project.

ADRs capture significant design decisions: what was decided, why, and what trade-offs were accepted.

## Format

Files are named `NNN-short-title.md` where `NNN` is a zero-padded sequence number.
